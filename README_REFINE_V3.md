## What changed and why

| Change | Purpose |
|---|---|
| Fresh noise and sigma on every microbatch | Remove dependence on only eight cached noise examples per training clip |
| Rank 16 instead of 8 | Test more adapter capacity; does not establish that rank 8 was the cause |
| LR 3e-4 for one clip, 2e-4 for full run | Test a stronger update; measured smoke/validation must establish stability |
| Normalized latent-motion reconstruction | Give temporal differences more influence relative to static appearance |
| Reverse-vs-forward endpoint hinge | Explicitly penalize a clean-latent estimate that is closer to the paired forward target |
| CFG=1 in the one-clip diagnostic | Remove unconditional-guidance complications while testing learnability |
| Adapter/base velocity RMS difference | Check that trained weights actually affect predictions |
| One-clip test before full training | Separate basic learnability/pipeline failures from generalization failures |
| Default transported-KD weight 0 | Isolate a potentially biased approximation; compare with the optional matched KD ablation later |

Changing several variables makes V3 a practical diagnostic/refinement experiment, not a controlled attribution of the V2 failure. For research claims, run matched ablations after establishing visible reverse motion.

Default V3 uses **teacher-sample distillation**: targets are reversed videos generated by a frozen teacher. It does **not** use velocity/feature KD by default. The optional separate KD run adds the original transported velocity targets every fourth update with appropriately scaled weight. Describe the two methods separately in your report.

## Interpretation

Endpoint-order preference on noised training targets is a diagnostic surrogate, not a calibrated temporal direction detector. It can exploit appearance/boundary differences. Low flow loss, adapter movement, a favorable hinge score or successful one-clip memorization cannot establish generalization. Count actual inverse-action completion in generated videos. Four test clips give a coarse success rate (25 percentage points per clip), and this test set has already been inspected in V2.

The new 1.3B T4 experiment has not been run by the author. No success rate, trained weights or faster runtime is claimed. Stop at the first failed diagnostic and use the saved evidence to decide the next change.
